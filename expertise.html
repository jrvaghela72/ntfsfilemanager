Case study · our own product

Open Windows drives on Android, without root

Android cannot write to NTFS, and many phones cannot read it at all. People with a Windows USB drive had to find a PC first. The app fixes that on the phone, then grew into a full file manager.

What we built

  • Full NTFS read and write through the open-source libntfs-3g driver, compiled for Android and called from Kotlin over JNI
  • An exFAT implementation written in plain Kotlin, including formatting drives from the phone
  • One explorer across internal storage, USB, Dropbox, OneDrive, and SMB, SFTP, FTP and WebDAV shares
  • The phone as a browser, WebDAV or FTP file server, protected by a PIN, with QR pairing
  • Google Play Billing subscriptions, and Google’s consent flow before personalised ads

How we keep it reliable

  • Tests run against real fixtures: generated exFAT disk images, and embedded servers on real sockets
  • Path-traversal attacks are tested over raw sockets, because an HTTP client quietly removes “../” before sending
  • Credentials are stored with Android Keystore-backed encryption, and never fall back to plain storage
  • GitHub Actions runs CI and deploys to Google Play; trade-offs are written down as architecture decisions (42 so far)
