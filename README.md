# NTFS File Manager — support site

Public support site for the NTFS File Manager Android app: Help & Feedback, Privacy Policy,
and Terms of Service. Hosted via GitHub Pages, served from this repo's `master` branch root.

Live at: https://jrvaghela72.github.io/ntfsfilemanager/

The app itself lives in a separate, private repository — this repo exists solely to host these
public-facing pages and the public issue tracker linked from them.

## Structure

- `index.html` — Help & Feedback
- `privacy-policy.html` — Privacy Policy
- `terms-of-service.html` — Terms of Service
- `assets/style.css` — shared styling

Plain HTML/CSS, no build step. Edit a page and push to `master` — GitHub Pages redeploys
automatically within a minute or two.
